# Type-G Smart — مشروع إعادة البناء (بدون تفعيل)

مشروع Android Studio نظيف، بنفس معمارية وبروتوكول النسخة 1.2.1، **من غير نظام التفعيل/التليجرام**.

## الفتح والبناء
1. Android Studio → Open → اختار فولدر `TypeGSmart`.
2. هيكمّل تنزيل Gradle wrapper تلقائيًا (أو شغّل `gradle wrapper` مرة).
3. اعمل **مفتاح توقيع جديد** (Build → Generate Signed Bundle/APK) — المفتاح القديم ضاع، فأي نسخة جديدة توقيع جديد.
   > تذكير: مش هتتسطّب فوق النسخة القديمة؛ لازم إزالة القديمة الأول.

## المعمارية
- `MainActivity` → WebView + جسر `Type-G`، بيحمّل الواجهة من `assets/` على `https://typegsmart.local/`.
- `TypeGBridge` → ينفّذ أوامر الواجهة ويبني الحالة `S`. التفعيل متشال: بيرجّع `license.active=true` دايمًا.
- `ControlService` → foreground service.
- `ControlEngine` → TCP server على 10086 + بروتوكول `up:` (زي الأصل بالظبط) في `Protocol.java`.
- `EnergyStore` → SQLite `energy.db` بنفس المخطط.
- `Wol` → Wake-on-LAN.
- `Discovery` → اكتشاف الموبايل بدون IP ثابت (تحت).


## التحقق والبناء الخارجي
- **فحص الترجمة:** كل كود الجافا بيترجم نظيف (javac ضد stubs لواجهات أندرويد) — اتمسك واتصلح باج نوع في الجسر أثناء الفحص.
- **بناء APK فعلي على GitHub:** فيه `.github/workflows/build.yml` — ارفع المشروع على GitHub، ومع كل push هيتبني الـ APK على سيرفرات GitHub (SDK كامل) وتلاقيه في Actions ▸ آخر run ▸ Artifacts باسم `TypeG-Smart-debug-apk`. أي خطأ بناء هيظهر في اللوج.
- **محليًا:** افتح المشروع في Android Studio (هيولّد الـ Gradle wrapper تلقائيًا)، أو شغّل `gradle wrapper` مرة وانت متصل بالإنترنت ثم `./gradlew assembleDebug`.

## اكتشاف الموبايل بدون IP ثابت (جديد)
المشكلة: المشترك بيتصل على IP الموبايل، والـ IP بيتغيّر/بيختلف من موبايل لموبايل.
الحل في `Discovery.java` — مسارين، اختار اللي فيرموير المشترك يقدر عليه:

### المسار 1 — UDP Discovery (موصى به للفيرموير البسيط)
- الموبايل يسمع UDP على البورت **10087**.
- المشترك يبعت broadcast نصه `typeg?discover` على `255.255.255.255:10087`.
- الموبايل يرد unicast بـ JSON:
  ```json
  {"typegsmart":1,"ip":"192.168.1.x","port":10086}
  ```
- المشترك ياخد `ip` ويفتح TCP على `10086` زي ما هو في البروتوكول الحالي.
- احتياطيًا: الموبايل كمان يعمل announce broadcast كل 5 ثواني بنفس الـ JSON، فلو المشترك بيسمع بس من غير ما يبعت probe، برضو هيلاقيه.

> كده المشترك مش محتاج أي IP ثابت؛ بيكتشف الموبايل تلقائيًا على أي شبكة.

### المسار 2 — mDNS / NSD (المعيار القياسي)
- الموبايل يعلن خدمة `_typeg._tcp` باسم `TypeGSmart` على 10086.
- لو فيرموير المشترك بيدعم mDNS client، يدوّر على الخدمة دي ويتصل بالاسم.

## حاجات متكتوبة كنقطة امتداد (محتاجة تكملة حسب جهازك)
- **قراءات الواط (watt sampling): اتعملت** — `Protocol.parseInfo()` بيحلّل رد `up:getinfo:` (قص 11 حرف، تقسيم `:`=8 أجزاء/4 مخارج، بيانات كل مخرج `;`=12 حقل، الحقل[1]=الحالة، الحقل[5]/1000=الواط)، و`ControlEngine.ingestReadings()` بيسجّل العينات ويحسب Wh والتكلفة ويكاملها (لو الفرق الزمني < 30 ثانية).
  - التعريفة بتتقري من `tariff.rate` (جنيه/kWh) في SharedPreferences — اتأكد إن `saveTariff` من الواجهة بيبعت `rate` بنفس الاسم، أو عدّل المفتاح في `ingestReadings`.
- **المؤقتات (timers): اتعملت** — `timer {mac,channel,seconds,state}` بيجدول تشغيل/فصل، و`seconds<=0` بيلغي. استطلاع دوري كل `pollSeconds` بيحدّث القراءات.
- **تنفيذ القواعد/المشاهد (rules/scenes):** دلوقتي بتتخزّن وتترجع في الحالة؛ منطق التشغيل التلقائي محتاج يتوصّل بالمحرك.
- **الويدجت والدليل (GuideActivity/Widget):** مش متضمّنين في النسخة دي؛ نقدر نضيفهم بعدين.
